## Coverage

- All **121 named UI states** have generated visual references; none remains unassigned.
- All **82 exact UI variants** have explicit parent artwork and fixture/control substitutions.
- All **146 world storyboard frames** have illustrated or documented derivative references.
- All **35 action families** and **15 item-detail types** have appearance/contact/state references.
- RP-01–RP-05 supply the guide-level house, square, identity/contact, camera/occlusion and pacing contracts.

[Machine-readable coverage](coverage.json) and the [reference map](reference-map.json) distinguish actual images from documented derivatives. Reuse is never falsely counted as another independently generated picture or finished animation.
