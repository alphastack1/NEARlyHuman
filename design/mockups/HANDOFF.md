## How to use the guides when building

1. Use the [master design](../../NEARlyHuman.md) for rules, economics, onchain save ownership and the request/preparation/settlement/replay lifecycle. Use the [scene map](../SCENE_MAP.md) for each mode's safe controls and exits.
2. Use VR-01 for color/material/pixel language; [RP construction references](../reference-pack/README.md) for topology, anchors, square/HUD bounds, pivots/camera and timing guidance. Generated furniture positions, meter fills and border aspect are approximate.
3. Implement one reusable overlay/detail/picker/progress system. Token/network/account context, accepted request state, life status and saved replay index choose data and actions. Do not trace pictures into a pile of independent pages.
4. Follow the complete reference map for a derivative: use its actual target, input, deadline, label and enabledness. The image cannot add stock, a heal, a random roll, a second model call or another lifetime tick.
5. Start the implementation sequence with the agreed narrow deterministic slice, actual procedural source art and recorded receipts before expanding the full content catalog.
