# NEARlyHuman — six website directions

4 November 2026. Six fresh independent designers, one shared research pack, **three separate imagegen mockups per direction**. These are alternatives for owner selection, not a deployed website or a game redesign.

**Start with [the comparison gallery](index.html).** Open the file directly in a browser; no server, package install, account or internet connection is required to view the local mockups. Switch Homepages / The game / Guides to compare the same layer. Click an image to enlarge, use arrows to see that direction's other pages, or open its original PNG. ## What happens after selection

Choose a whole direction or combine specific strengths, for example a world-led homepage with the almanac's guide typography. The chosen direction then receives real responsive layout, exact game captures/art inserts, lightweight animation and actual website routing. A future app entry must preserve existing exact-NFT links, selected-world context and interrupted-wallet recovery.

All concepts keep the conspicuous **Open App** path. Wallet connection remains in the existing app; docs remain publicly readable. The candidate handbook moves from first day/care to ownership, worlds/wallets and deeper Jev/contracts/help. It must describe the actual two testnet worlds and current rules, without invented mainnet, traders, guaranteed returns or offline aging.

The original procedural rooster was not redrawn or changed. Environment and object artwork in these mockups explores website presentation rather than new playable maps. Production rooster inserts must use the existing canonical generator exactly. Small lettering/icon/crop imperfections in generated images are implementation notes; they do not create new game rules.

All final images were generated with the **built-in image generation tool**, not the API/CLI fallback. Full prompts, reference roles, tool output provenance and per-set critique are stored in each NOTES.md/manifest.json. The final local gallery and assets do not depend on TEMP. No main push, deployment, financial operation or game source edit is part of this exploration.
