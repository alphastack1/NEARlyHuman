## Frozen inputs and recovery

The latest prior-day state hash must match the packed request base. The normalized array is saved in the fenced job record and copied into checkpoints; genesis has an explicit empty array.

Transient history/storage interruption queues before spending. Changed canonical history, invalid frozen input or checkpoint mismatch quarantines the request. Restart retains the cached planner answer and frozen memory, without rereading history or buying another planner. The [focused worker regression](proofs/worker-memory-proof.json) records these cases; its existing service/storage run passed 11 tests before the separate fork-adoption regression was added.
