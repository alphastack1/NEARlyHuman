# Artwork and media credits

The rooster is the project owner's original procedural artwork. Its seeded shape, palette, accessories and poses come from [`src/art/rooster.ts`](../../src/art/rooster.ts) and [`rooster-data.ts`](../../src/art/rooster-data.ts).

| Media | Content |
| --- | --- |
| `readme-cover.webp` | The implemented website with its environment illustration and original rooster. |
| `nft-lives.webp` | Eight actual saved testnet lives, illustrated from their recorded home, garden and inventory state. |
| `gameplay.gif` | MISO's saved Day 28, played faster for the README. Playback does not prepare another AI day. |

The website house and handbook environment illustrations were created with OpenAI image generation for this project. Their original source images are in [`assets/source/website/`](../../assets/source/website/); optimized web derivatives ship in [`public/site/`](../../public/site/).
