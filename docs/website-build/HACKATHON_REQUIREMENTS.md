# Submission requirements checked 4 November 2026

Primary sources: [official hackathon website](https://nearhackathon.com/) and [organizer submission checklist](https://github.com/nearai/near-hackathon-prompt-examples/blob/main/SUBMITTING.md).

- Submit a working prototype in a **public project repository**. A contracts-only download does not replace the repository judges need to clone.
- Include reproducible README instructions, with observable actions/results. Review history for secrets before publication.
- Provide a public X demo post naming the hackathon, with video/screenshots, @NEARProtocol and #NEARHackathon. Both repository and demo links are required.
- Deadline: **14 November 2026, 23:59 UTC**, or **15 November, 06:59 Bangkok time**.
- The checklist requests a **mainnet NEAR account for prize payout**. This is distinct from a game testnet wallet.
- The final submission cannot be edited afterward. Recheck the current rules and complete payload before submitting.

The owner approved contracts-only source publication during this sprint. Repository visibility remains a separate decision. Neither a submission nor an X post has been sent. This file records requirements, not an instruction to perform either action.
